# Common Permits to Audit For

**This list is a starting point, not exhaustive.** Permit requirements are jurisdiction-specific. Use `WebSearch` to verify the actual permits required, fee structure, and inspection-fee structure for the project's jurisdiction.

- **General building / construction permit** — almost always required
- **Electrical permit**
- **Plumbing permit**
- **Mechanical / HVAC permit**
- **Roofing permit** (some jurisdictions)
- **Gas permit** (often separate from plumbing)
- **Demolition permit** (when threshold of demolition is exceeded)
- **Asbestos / hazardous material permit** (where applicable)
- **Tree removal permit** (some jurisdictions)
- **Special-district permits** (HOA, historic district, coastal commission, FEMA flood)
