# Personal-Property Storage & Construction Debris Categories

**Both lists below are starting points, not exhaustive.** Apply additional industry-standard considerations as the project warrants.

## Personal-property storage / pack-out

For every room being worked on:

- **Pack-out** — labor and materials (boxes, packing paper, bubble wrap, tape, labels, shrink wrap on furniture).
- **Transport** — truck, mileage, crew hours.
- **Off-site storage** — monthly storage unit cost × number of months matching the construction timeline.
- **Climate-controlled storage** for moisture-sensitive items (wood furniture, electronics, leather, instruments) — separate code from standard storage.
- **Pack-back / re-installation** — same scope as pack-out, generally same cost.
- **In-home maneuvering** — pad-and-block (lifting/moving items within the home for floor or wall work, especially when full pack-out isn't justified).
- **Specialty items** — piano moving, gun safes, large aquariums, art handling — all separate and significantly more expensive.
- **Contents cleaning** (if smoke / soot / water exposure) — typically handled by a contents company.

The construction timeline determines storage duration. If the timeline grew (it usually does after a thorough audit), storage cost grew too.

## Construction debris and disposal

### Tonnage conversions (verify locally)

Square footage removed → tonnage. Use `WebSearch` to verify localized Xactimate conversion factors. Use `bash` with Python for the actual sums.

- Drywall: ~1.5 lb/sq ft, so ~3 tons per 4,000 sq ft removed
- Flooring (carpet/pad): ~0.5–1 lb/sq ft
- Tile/stone: heavy — 3–5 lb/sq ft
- Roofing shingles: ~2.5 lb/sq ft per layer (multiply by layer count)
- Concrete/masonry: substantial — separate hauling code

### Disposal items to audit

- **Dumpster sizing and count** — 20-yard, 30-yard, 40-yard, plus swap-outs for long projects.
- **Tonnage overage charges** — dumpster pricing typically includes a tonnage cap; supplement for actual tonnage if known.
- **Hazardous materials** — asbestos abatement (separate licensed scope), lead paint (RRP rules and disposal), refrigerant recovery from HVAC.
- **Recycling fees / tipping fees** — vary by jurisdiction. Use `WebSearch` to verify.
- **Specialty hauling** — mattresses, appliances (refrigerator with refrigerant), tires, electronics — each often a separate fee.
- **Daily haul-off** for projects without dumpster space (small lots, HOA restrictions).
- **Loading labor** — heavy debris loading is its own labor code; the carrier often only included the dumpster rental fee with no loading labor.
