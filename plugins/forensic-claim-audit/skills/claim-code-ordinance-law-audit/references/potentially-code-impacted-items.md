# Potentially Code-Impacted Item Categories

Common categories of line items that are subject to building code, ordinance, or law upgrade requirements.

**This list is a starting point, not exhaustive.** Apply additional industry-standard guidance for the specific project and jurisdiction. The actual code in force depends on the jurisdiction, the year of model code adoption, and any local amendments — verify each citation via `WebSearch`.

## Subject to code (add to the "potentially code-impacted" list)

- **Insulation** — code-required R-value
- **Drywall** — usually only fire-rated assemblies
- **Electrical** — AFCI in bedrooms, GFCI in kitchens/baths/exterior, tamper-resistant receptacles, neutral wire requirements
- **Smoke / CO detectors** — hardwired interconnected typically required after a certain damage threshold
- **Roofing** — ice & water shield, drip edge, nailing pattern, decking nail-off
- **Windows** — energy code U-factor / SHGC, tempered glazing where required
- **Plumbing** — low-flow fixtures in many jurisdictions, anti-scald valves
- **HVAC** — efficiency minimums, refrigerant transition
- **Stairs, handrails, guards** — height, baluster spacing
- **Egress** — window size, door hardware in bedrooms used as egress
- **Foundation / structural** — seismic retrofit in CA/PNW, hurricane straps in coastal zones
- **Accessibility upgrades** — after threshold-of-damage triggers ADA-aligned local rules

## Not subject to code (skip)

Cabinets, paint color, decorative finishes typically have no code dimension.

## Acceptable enforcement evidence

Per industry practice, it is legally insufficient that a code merely exists in a manual. The contractor must prove the local building official is **actively enforcing** it for *this specific repair project*. Evidence types — also a starting point, not exhaustive:

- A written directive from the local building official
- A failed municipal inspection report citing the requirement
- An official permit rejection letter from the city citing the code
- A documented past local-permit review on a comparable project

If you do not have enforcement evidence yet, recommend the contractor obtain it (typically a phone call or email exchange with the permit office documenting the requirement). Do not assert enforcement you cannot prove.
